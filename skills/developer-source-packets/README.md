# developer-source-packets

Build traceable source packets from public developer conversations before using them in marketing, DevRel, docs, or launch work.

## What This Skill Covers

- Turning vague listening requests into precise research questions
- Capturing public evidence from GitHub, Hacker News, Reddit, Stack Overflow, X/Twitter, docs, blogs, and forums
- Separating observed evidence from interpretation
- Recording URLs, authors, timestamps, visible metrics, confidence, and limits
- Handing packets to related skills without drafting or posting automatically

## Quick Start

1. Define the research question
2. Gather public source URLs or approved tool output
3. Normalize each item into the packet format
4. Summarize patterns with confidence and limits
5. Choose the next skill for content, comparison, listening, or X/Twitter strategy

## Optional X/Twitter Collection

Use manual URLs, screenshots, exports, or an approved source tool. TweetClaw can be used as an optional OpenClaw plugin or npm package for public X/Twitter search, tweet and reply lookup, follower export, media checks, monitoring, webhooks, and MCP tool output when the user already has it installed or asks for it.
